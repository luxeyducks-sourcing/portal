HOW A CUSTOM PROJECT MOVES
Customer consultation request -> LuxeyDucks internal review -> approved partner brief -> partner response -> LuxeyDucks pricing/review -> customer quotation -> documented design approval -> explicit production authorization.
These are separate drafts. Data is NOT transferred between them automatically.
Use the same project ID and revision manually until a backend is connected.
A request, a quote, and a design reference are NOT purchase orders or production authorization.

WHAT WORKS IN THESE DRAFTS
Navigation between the packaged local HTML pages.
Editable fields and local image previews where provided.
Embedded branding/reference images: no separate image downloads required.
Browser Print / Save as PDF, with controls hidden where configured.
The four pricing forms contain device-local autosave logic; this is not server storage and browser support varies.

WHAT IS NOT CONNECTED
Sign-in/access protection, email delivery, submission storage, server-side uploads.
Automatic transfer of project data between pages.
Automatic financial calculations in the request forms.
Autosave for the request forms, customer intake, and ring quotation builder.
Customer name/email required-field enforcement on the customer draft.
Customer privacy notice and final submission/consent wording.
All submit/sign-in buttons remain disabled placeholders.

IMPORTANT IMAGE / PDF NOTES
Image selectors provide local previews, NOT uploads to a server.
Images fit their frames without stretching; underlying files are not resized or compressed.
Local replacements and unsaved edits disappear when the page is closed/reloaded.
Save a PDF before closing. Check every page before sending it.
PDFs have not been rendered/visually validated here. Long notes and descriptions can overflow or add pages.
Do not call the quote a guaranteed one-page PDF until tested with realistic content.
